# Arman News Bot

Telegram-бот, который читает публичную веб-версию канала-источника
(`https://t.me/s/<channel>`), присылает новые посты админу на подтверждение
(кнопки «Опубликовать» / «Отклонить») и после подтверждения публикует их в
целевой канал.

## Как это работает

1. Каждые несколько минут (`POLL_CRON`) бот скачивает `https://t.me/s/SOURCE_CHANNEL`
   и парсит новые посты (те, у которых id больше последнего обработанного).
2. Для каждого нового поста бот шлёт превью в личку админу (`ADMIN_CHAT_ID`)
   с кнопками ✅ Опубликовать / ❌ Отклонить.
3. При нажатии «Опубликовать» бот отправляет текст/фото поста в `TARGET_CHANNEL`.
4. При нажатии «Отклонить» пост просто помечается обработанным и никуда не публикуется.

Поддерживаются текстовые посты и посты с одной фотографией. Видео и другие
типы медиа публикуются как ссылка на оригинал (веб-превью Telegram не отдаёт
прямую ссылку на видеофайл без JS).

## Локальный запуск

```bash
npm install
cp .env.example .env
# заполни .env (см. ниже)
npm start
```

## Переменные окружения

| Переменная | Что это | Пример |
|---|---|---|
| `BOT_TOKEN` | Токен бота от @BotFather | `123456:AA...` |
| `ADMIN_CHAT_ID` | Твой личный chat_id (куда слать превью) | `123456789` |
| `TARGET_CHANNEL` | Канал, куда публиковать подтверждённые новости | `@JetisNub` |
| `SOURCE_CHANNEL` | Канал-источник (без @ и без t.me/) | `uto92` |
| `POLL_CRON` | Cron-расписание проверки новых постов | `*/5 * * * *` |
| `PORT` | Порт для служебного HTTP-сервера (Railway) | `3000` |

Чтобы узнать свой `ADMIN_CHAT_ID`: напиши боту `/start` в личку, затем открой
`https://api.telegram.org/bot<ТВОЙ_ТОКЕН>/getUpdates` в браузере — там будет
`chat.id`.

## Деплой на Railway

1. Залей этот репозиторий на GitHub.
2. На [railway.app](https://railway.app) → New Project → Deploy from GitHub repo → выбери репозиторий.
3. В настройках сервиса (Variables) добавь все переменные из таблицы выше.
4. Railway сам определит `npm start` из `package.json` и задеплоит.

### Важно про хранение данных

Бот хранит id последнего обработанного поста и список постов, ожидающих
подтверждения, в файле `data/store.json`. На бесплатном плане Railway
файловая система эфемерна — при редеплое (не при обычном рестарте) она может
очиститься, и бот заново пришлёт несколько последних постов на подтверждение.
Это не критично (просто нажмёшь «Отклонить» на дублях), но если хочется
полной надёжности — подключи в Railway **Volume** и примонтируй его на `/app/data`.

## Настройка бота и канала (если ещё не сделано)

1. Создай бота через [@BotFather](https://t.me/BotFather): `/newbot`.
2. Добавь бота администратором в целевой канал с правом «Публикация сообщений».
3. Напиши боту `/start` в личку, чтобы он мог прислать тебе `ADMIN_CHAT_ID`.
